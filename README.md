# EduNotes — Full-Stack Educational Management Platform

A complete school management system supporting multi-role workflows 
with real-time notifications and multilingual support.

---

## 🚀 Features

### Multi-Role System
- Separate dashboards for Admin, Teacher, and Student
- Role-based authorization and access controls
- Admins manage users, classes, subjects, and degrees
- Teachers handle assessments and grade entry
- Students access grades, transcripts, and personal statistics

### Grade Engine
- Supports numeric scores, absences (ABS), and waivers (DISP)
- Automated bulletin and transcript generation
- Per-subject and semester averages

### Backend Architecture
- RESTful API with layered architecture
- Advanced pagination and filtering
- Structured logging with Winston

### Security
- JWT signed with RSA asymmetric keys
- bcrypt password hashing
- Strict input validation (Joi/Yup)
- Role-based access control middleware

### Real-Time & UX
- Live notifications via Socket.io
- Responsive React 18 frontend with Ant Design
- Interactive tables and visual dashboards

### Internationalization & DevOps
- Full i18n in French, English, and Arabic
- Containerized with Docker
- Tested with Jest, linted with ESLint/Prettier

---

## 🛠 Tech Stack

**Backend:** Node.js · TypeScript · Express.js · MongoDB · Socket.io  
**Frontend:** React 18 · TypeScript · Redux Toolkit · Ant Design · Vite  
**Security:** JWT · RSA · bcrypt · Joi · Yup  
**DevOps:** Docker · Jest · ESLint · Prettier · Winston
